# Licenses

`flexo-rtm` uses a three-license split, mirroring [`ant-rdf`](https://github.com/mzargham/ant-rdf) and the [`flexo-rtm-research`](https://github.com/dynamicalsystemsgroup/flexo-rtm-research) companion repo.

| Artifact class | License | Full text |
|---|---|---|
| **Code** (everything under `oracle/`, `tests/`, build scripts, `Makefile`, `pyproject.toml`) | Apache-2.0 | [LICENSE-CODE](LICENSE-CODE) |
| **Documentation** (`README.md`, `CONTRIBUTING.md`, `CLAUDE.md`, anything markdown not inside an ontology file) | CC-BY-4.0 | [LICENSE-DOCS](LICENSE-DOCS) |
| **Ontology** (every `*.ttl`, `*.shacl.ttl`, `manifest.yaml`, and ontology examples) | CC0-1.0 | [LICENSE-ONTOLOGY](LICENSE-ONTOLOGY) |

Every source file carries an `SPDX-License-Identifier` header matching its class. The header is the contributor's per-file declaration; this file is the index.

By contributing you agree your changes are licensed under the artifact-class terms above. No CLA required.
